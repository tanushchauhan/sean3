# Launcher and fresh setup: October 29, 2026

Step 4 makes SEAN 3 runnable without knowing its internals. The `./sean3`
script sets up, checks and runs the simulator; a fresh clone on robovision
followed [the getting-started guide](../getting-started.md) to a running,
navigating simulation with no manual steps.

## What was added

- `./sean3` (sean3 `003d3ea`): `setup`, `build-player`, `doctor`, `run`,
  `next-task` and `reload-scene`. `run` starts the ROS endpoint container, the
  simulator, Nav2 and a task driver, waits for each, and on Ctrl+C or a crash
  stops them in order and removes the container. Startup failures stop before
  anything starts and name the fix.
- `sean_task_driver` (ROS `234262d`): sends each task's goal to Nav2 once, as the
  qualification checker does, clears costmaps after the teleport, and requests
  the next task when Nav2 finishes. A new task or scene reload replaces the
  running goal.
- Product name `SEAN 3` (Unity `537ec00`), the getting-started guide, and the
  documentation moved into `docs/`.

## Fresh setup

In an empty directory, with no personal Git configuration:

| Step | Time | Result |
| --- | ---: | --- |
| `git clone` and branch switch | 1 s | ok |
| `./sean3 setup` | 12 min | Fetched pinned sources; built `Dockerfile.humble` from scratch (tf2 and tf2_ros 0.25.24, navigation2 1.1.20); built the ROS package |
| `./sean3 build-player --unity ...` | 6 min | Built from the fresh `sources/` checkout at Unity `537ec00` |
| `./sean3 doctor --gpu egl4` | 1 s | All checks ok |
| `./sean3 run --gpu egl4 --record ...`, 5 min | | 3 tasks succeeded with the same goals and times as the earlier run; clean Ctrl+C |

This is also the first successful from-scratch build of the ROS image. Its
package versions come from the Ubuntu and ROS archives on the build date, so a
later rebuild can differ; pinning them belongs to the release freeze.

## Limits

- Tested on one machine (robovision: Ubuntu, rootless Podman, NVIDIA), with a
  virtual display. A desktop session window was not tested.
- Unity was already installed and activated; installing Unity is not covered.
- The fresh-setup run used an empty Warehouse. Crowd navigation remains limited
